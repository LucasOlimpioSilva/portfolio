# 💼 Lucas Olimpio | Portfolio

Meu portfólio como Desenvolvedor Full Stack, desenvolvido para apresentar meus projetos, habilidades e trajetória na área de desenvolvimento.

O objetivo deste projeto é criar uma experiência moderna, responsiva e intuitiva, colocando em prática conceitos de HTML, CSS e JavaScript, além de servir como um espaço para compartilhar minha evolução profissional.

---

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- Git
- GitHub

---

## ✨ Funcionalidades

- Apresentação profissional
- Lista de projetos
- Links para GitHub e demonstrações
- Download do currículo
- Layout responsivo
- Animações suaves
- Scroll dedicado para navegação entre projetos
